# Smart Attendance System

A production-ready attendance management application for educational institutions.

## Stack

- **Backend**: Node.js 18+, Express.js, MongoDB + Mongoose
- **Frontend**: React.js 18+ (functional components + hooks, React Router DOM v6)
- **Auth**: JWT + bcryptjs
- **Security**: helmet, mongo-sanitize, express-rate-limit, express-validator, cors

## Getting Started

```bash
# Backend
cd backend
copy .env.example .env
npm install
npm run seed
npm run dev

# Frontend
cd frontend
copy .env.example .env
npm install
npm start
```

## API Version

All routes are prefixed with `/api/v1`.
